## 可以用来做什么

- **微信和支付宝扫码收款**。开通所需渠道，上传自己的收款码。买家按订单页面显示的金额扫码付款，款项进入所用收款码对应的账户。

## 怎么开始

1. 在官网申请入驻，按页面提示提交资料并开通所需渠道。
2. 在商户后台上传自己的收款码，需要通知辅助匹配时绑定收款设备。
3. 在网站或小程序创建订单，小额测试扫码、到账核对和订单状态更新，再用于实际业务。
